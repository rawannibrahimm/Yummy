# 🍽️ Yummy - JavaScript Project

A dynamic web application that explores meals using a public API.
The project demonstrates how to fetch, process, and render API data dynamically using **vanilla JavaScript**, while applying important software design principles like **DRY (Don't Repeat Yourself)** and modular code organization.
This project was developed as part of my journey learning **JavaScript, DOM manipulation, and API integration**.

---

# 📌 Project Overview

Yummy is a client-side web application that allows users to:

- Search for meals by name or first letter
- Explore meal categories
- Browse meals by country(area)
- Filter meals by ingredients
- View detailed meal instructions and ingredients
- Use a contact form with input validation

The application dynamically fetches data from an external API and renders it into the DOM without reloading the page.

---

# 🚀 Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript (ES6+)

External API used:

- TheMealDB API (Free meals database) : https://www.themealdb.com/api.php

# ⚙️ Core Features

## 🔎 Meal Search

Users can search meals using:

- Meal name
- First letter of the meal

The results are fetched from the API and displayed dynamically.

---

## 📂 Categories

Displays available meal categories and allows users to explore meals inside each category.

---

## 🌍 Area Filtering

Users can explore meals by country or region.

---

## 🥕 Ingredient Filtering

Allows browsing meals based on specific ingredients.

---

## 📋 Meal Details

When a user clicks on a meal card, the application displays:

- Meal instructions
- Ingredients
- Tags
- Source links
- YouTube tutorial

---

## 📞 Contact Form

Includes client-side validation for:

- Name
- Email
- Phone
- Age
- Password

Validation messages guide users to enter correct information.
